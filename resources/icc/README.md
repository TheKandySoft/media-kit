# sRGB profile

`sRGB-v2-micro.icc` — a compact ICC v2 sRGB profile from
[Compact-ICC-Profiles](https://github.com/saucecontrol/Compact-ICC-Profiles) by Clinton Ingram,
released into the public domain under CC0 1.0. Used to convert pictures shot in a wider colour
space (Display P3, Adobe RGB) to sRGB before they are resized and published.
